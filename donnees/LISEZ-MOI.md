# Données

Le fichier de données n'est pas inclus dans ce dépôt (43,5 Mo, et la licence demande seulement de citer la source).

1. Télécharge **Online Retail II** sur le site de l'UCI : https://archive.ics.uci.edu/dataset/502/online+retail+ii
2. Dézippe l'archive. Tu obtiens un fichier Excel avec deux feuilles (deux périodes).
3. Ouvre le rapport Power BI, puis **Transformer les données > Gérer les paramètres** et mets le chemin du fichier dans `p_FichierSource`.

Source : Online Retail II, UCI Machine Learning Repository (page ci-dessus). Licence CC BY 4.0 : cite la source si tu réutilises les données.
